# 🌦 Telegram Бот Погоды (Prognoz Bot)

Простой, элегантный и надежный Telegram-бот для просмотра прогноза погоды на 4 даты: **Вчера**, **Сегодня**, **Завтра** и **Послезавтра**.

---

## 🚀 Возможности

- **Главное меню**: Быстрый выбор дня по нажатию на инлайн-кнопки (Вчера, Сегодня, Завтра, Послезавтра).
- **Фактическая погода (Вчера)**: Использование historical/archive API Open-Meteo для получения фактических данных за прошлый день.
- **Подробный почасовой прогноз**: Кнопка `[ 🔎 Подробнее ]` (только для сегодняшнего дня) выводит почасовой прогноз погоды с 00:00 до 23:00.
- **Навигация**: Удобные инлайн-кнопки `[ ◀️ Назад ]` и `[ 🔄 Обновить ]` с обновлением существующих сообщений (без захламления чата).
- **Часовые пояса**: Корректный расчет дат и времени с учетом часового пояса выбранного города пользователя.
- **Интерактивный выбор любого населенного пункта**: Поддержка не только крупных городов, но и малых городов, посёлков (пгт), станиц, сёл и деревень. Поддерживает ввод с приставками («деревня Простоквашино», «пгт Шерегеш», «село Болдино»), уточнение региона через запятую («Константиново, Рязанская область») и интерактивный выбор кнопками при наличии нескольких одноименных пунктов.
- **Кэширование**: Встроенный кэш запросов погоды для снижения нагрузки на API (с возможностью принудительного обновления кнопкой «Обновить»).

---

## 🛠 Технологии

- **Python 3.12+**
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram ботов.
- **httpx** — быстрый асинхронный HTTP-клиент.
- **SQLite & aiosqlite** — легковесная асинхронная база данных для хранения профилей пользователей.
- **Open-Meteo API** — бесплатное погодное и геокодировочное API без необходимости получения API-ключа.
- **Docker & Docker Compose** — контейнеризация для простого запуска.

## ⚙️ Настройка `.env`

Создайте файл `.env` в корне проекта на основе `.env.example`:

```env
BOT_TOKEN=ваш_токен_телеграм_бота
DATABASE_PATH=weather_bot.db
```

Получить токен бота можно у [@BotFather](https://t.me/BotFather).

## 💻 Установка и локальный запуск

1. **Клонируйте репозиторий / перейдите в папку проекта**.
2. **Создайте и активируйте виртуальное окружение**:
   ```bash
   python -m venv venv
   # На Windows:
   venv\Scripts\activate
   # На Linux/macOS:
   source venv/bin/activate
   ```
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Создайте файл `.env` и укажите ваш `BOT_TOKEN`**.
5. **Запустите бота**:
   ```bash
   python main.py
   ```

## 🐳 Запуск через Docker

Запуск бота в контейнере с сохранением базы данных SQLite в томе `bot_data`:

```bash
docker compose up -d --build
```

Для остановки контейнера:
```bash
docker compose down
```

## 🌐 Используемое API Open-Meteo

1. **Geocoding API**: `https://geocoding-api.open-meteo.com/v1/search`
   - Используется для поиска координат города, страны и часового пояса (`timezone`).
2. **Weather Forecast API**: `https://api.open-meteo.com/v1/forecast`
   - Используется для получения текущего, будущего прогноза и почасовых данных на сегодня, завтра и послезавтра.
3. **Historical Archive API**: `https://archive-api.open-meteo.com/v1/archive`
   - Используется для получения фактических/исторических погодных данных за вчерашний день.
